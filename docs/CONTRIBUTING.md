# Contributing

Ally Hub is a personal project built for my own ROG Xbox Ally X. It's public in case it helps others.

- **Found a bug?** Open a [Bug report](https://github.com/Ravenor907/AllyHub/issues/new?template=bug_report.yml).
- **Have an idea?** Open a [Suggestion](https://github.com/Ravenor907/AllyHub/issues/new?template=suggestion.yml). Every one gets a reply,
  but I decide what goes into the app.
- **Pull requests** are welcome but may not be merged. Please open a suggestion first.
- Run `python3 tests/run_tests.py` before submitting code. It runs without a handheld or Qt.
